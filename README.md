# Lung Cancer Detection Using Deep Learning

## Project Description

This project uses a Deep Convolutional Neural Network (CNN) to classify lung scan images into two categories: Normal and Lung Cancer.

The project includes model training, evaluation, and a Streamlit-based application for image prediction.

## Features

- Lung scan image classification
- Deep CNN model
- Image preprocessing and augmentation
- Model evaluation using Accuracy, Precision, Recall, F1-score and ROC-AUC
- Confusion Matrix and ROC Curve
- Streamlit web application for prediction

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- PIL
